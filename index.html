HOW TO USE

KIKUtabの使い方

  1. 1 入力・編集を開く 譜面のすぐ下に入力ボタンが表示されます。
  2. 2 音符や休符を選ぶ 選んだ記号が譜面の最後に追加されます。
  3. 3 五線譜 / TAB譜を切り替える 同じリズムを別の見え方で確認できます。TAB譜でも音のタイミングは同じです。
  4. 4 音で確認する 再生するとリズムを実際に聴くことができます。TAB情報を入れた音は弦とフレットに応じた高さで鳴ります。
TAB RHYTHM GUIDE

TAB譜のリズムの読み方

TAB譜の数字だけでは、弾くタイミングは分かりません。 数字は「どこを押さえるか」、符幹・連桁・休符などは「いつ弾くか」を表します。

  1. 1数字はいったん無視最初は弦やフレットではなく、リズムの形だけを見ます。
  2. 2リズム表記をKIKUtabに写す手元のTAB譜と同じ符幹・連桁・休符の形を選びます。
  3. 3数字なしで再生するまずタイミングだけを耳で確認します。
  4. 4必要なら弦・フレットを入力TAB譜の○をタップし、左から順に「弦 → フレット」を入力します。

譜面をクリアしますか？

入力した譜面をすべて削除します。 この操作は元に戻せません。
