# KIKUtab UI Prototype

次期KIKUtabのUI/UXを比較するための独立プロトタイプです。

## 重要

- 本番用の `index.html`、`style.css`、`app.js` は使用・変更していません。
- GitHub Pagesへは公開しません。
- 本番の保存データにはアクセスしません。
- ログイン、課金、広告、クラウド保存などは含みません。
- 譜面描画と音声は、UI検証に必要な範囲だけの簡易実装です。

## 開き方

`ui-prototype/index.html` をブラウザで開いてください。

ローカルサーバーを使う場合は、リポジトリのルートで次を実行します。

```text
python -m http.server 8000
```

その後、次を開きます。

```text
http://localhost:8000/ui-prototype/
```

## 試せる操作

1. 音符／休符を選択
2. 音の長さを選択
3. 1〜6弦を選択
4. 画面内の数字キーで0〜24フレットを入力
5. TAB情報を決定
6. 譜面上の音をタップして選択・TAB変更・削除
7. Undo／Redo
8. 再生／停止／先頭／ループ／速度変更
9. 再生カーソルと現在音のハイライト

## 画面設計

- スマートフォン：ヘッダー、譜面、再生UIを上部に維持し、その下で現在必要な入力だけを表示
- PC：譜面と入力パネルを左右へ分け、縦スクロールを削減
- 譜面：880pxを維持し、譜面部分だけ横スクロール
- タップ領域：主要操作は44px以上

詳しい比較と採用判断は `COMPARISON.md` を参照してください。
